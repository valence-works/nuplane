# Scoped Manifest desired-source reads

This increment implements the Manifest source's bounded [before-read admission](../contracts/admission.md). `DesiredManifestPackageSource` implements `IScopedDesiredPackageSource`; the additive reader overload carries the caller's exact counted borrow. Positive Unenrolled reads remain compatible. Scoped reads require the exact Complete root, keep path restrictions and retain ownership through the native read, parsing and source projection. Disabled sources do not read their configured path.

The Manifest reader uses a separate native direct-child text-read boundary. It retains the parent identity/profile, performs the first payload open relative to that parent with no-follow semantics, and verifies regular single-link type, canonical basename and native identity. Unix retains a nonblocking shared file lock and measures length after acquiring it. Windows retains ReadData/ShareRead access. Both read bounded chunks of the observed length while ownership stays live across awaits, then replay parent/name/profile/identity/length before returning bytes. Missing entries and ordinary directories remain NotFound; empty/malformed JSON remains Invalid. Unclassifiable authority failures stay typed refusals. A positively verified native read/lock failure can remain Unreadable.

Parsing shares the existing validation and deterministic projection. StreamReader BOM detection preserves UTF-8, UTF-16 and UTF-32 behavior. Correlation, configured schema, source/feed names, exact update policy, metrics and LastReadResult remain intact. The runtime source adapter preserves the original source type's legacy identity for ordering, errors and cached snapshots, so different scoped source types do not overwrite one another under the common wrapper name.
