# Participant host-integrated loading

`NuplaneHostIntegratedLoader.LoadFromParticipantAsync` accepts only the sealed access object registered by a validated coordinated composition. Ordinary offline state/package entry points retain released compatibility. The participant route acquires the process composition gate before opening a Loading-purpose snapshot over the complete catalog, then joins host graph grouping to exact verified persisted active candidates. It never fabricates missing graph or install facts.

Each candidate is bound to current native install identities and published as graph-use protection while the original snapshot ownership remains held. The short snapshot is released before metadata, activation callbacks or assembly reads. The existing scoped loader validates the complete selection and gate set before dispatch and transfers protection to actual noncollectible contexts. Untransferred owners drain on failure; transferred protection lasts until process exit. Repeated loads require the same frozen composition, persisted graph identity, exact paths, context and native lease. An equivalent reordered roster is accepted; a newly published graph identity for the same IDs/versions is refused.

A graph must currently match one complete persisted candidate on one physical root. Legacy/unknown closures, unmatched overlapping compositions and unsupported participants refuse; they do not acquire ordinary fallback authority.
