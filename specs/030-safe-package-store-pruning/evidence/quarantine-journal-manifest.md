# Detached quarantine journal and native manifest prerequisite

This increment implements descriptive prerequisites for the [quarantine/recovery contract](../contracts/quarantine-recovery.md). It does not implement fresh execution planning, durable journal publication, quarantine recovery, recursive deletion or public activation. T106/T107/T111/T118 stay open.

## Implemented evidence boundary

The immutable manifest binds its native install-directory identity/profile and every descendant's exact relative components, kind, identity and parent/profile. Directory rows also bind their own profiles. Structural validation rejects duplicate paths/objects, invalid parent relationships, different volumes, invalid encodings and fixed entry/child/depth bounds. Rows sort by ordinal component sequence, including the `a/z` versus `a-/x` boundary. Exact-subset comparison reports missing rows and refuses added/replaced survivors; markerless or empty observations never grant authority.

The journal separately requires the full root completion-marker baseline and matching completion digest, original logical install identity, root/epoch, distinct operation/candidate IDs, package-parent locator/identity/profile, canonical quarantine name, retention confirmation and one supported phase. Its strict bounded JSON codec rejects missing (including nullable), unknown, duplicate, malformed and inconsistent fields. Canonical integrity encoding binds the journal fields; integrity is not current namespace evidence.

`PhysicalStoreDeletionManifestReader` walks provider-owned held native handles without moving, unlinking or reading payload bytes. It uses bounded complete enumeration, no-follow inspection/open, actual native identity/canonical-name/profile checks, same-volume membership, unique objects and single-link regular files. It re-enumerates and rechecks each directory, its children, and the install parent. The completion marker must be an exact empty regular file with the original identity-derived digest. A held leaf plus a supplied identity does not establish root containment or a logical path: the future caller must retain and revalidate the catalog-owner/root-to-parent binding, then bind journal parent/name facts from that same observation.

They cover exact nested capture/nonmutation, same-identity quarantine, actual missing payload/empty-directory subset facts, added/replaced survivors, symlinks/hard links, malformed or same-name-replaced completion markers, mismatched identities/digests, wrong-volume roots, foreign/disposed handles, direct-child/depth limits and cancellation. A compiled completion-digest omission causes the real mismatch regression to fail with no exception thrown. Production source is restored byte-for-byte and the strict 13-case suite passes again.

Independent static review accepted the bounded capture boundary and root added the same-name marker replacement case and explicit ancestry limitation. Remaining integration coverage includes real bound-owner capture-to-move/close order on Windows, same-volume wrong-root/path replay, capture-time races, aggregate native entry count/encoding bounds, journal publication phases and actual restart recovery. Pure models/codecs cannot replace these gates.
