This bounded T074/T084/T091 follow-on implements Directory feed reads through the original Complete root owner or positive Unenrolled authority. It does not accept those tasks, T101, the full before-delete gate or pruning. Enabled DesiredManifest support remains required separately.

`DirectoryNupkgDesiredSource` implements the additive scoped source companion, preserving its constructor and source/feed attribution, allowlist, exact policy, highest NuGet version and deterministic ordering. A core native directory session resolves original path components, retains the supplied owner through enumeration and stability awaits, and replays ancestry, names, profiles and authority. It never reacquires root ownership or opens an absolute payload path. Positive missing feeds stay empty; foreign, incomplete, uncertain, linked, hardlinked or unsupported candidates raise typed refusal rather than becoming unstable or empty.

Before an initial successful sample, verified Busy metadata does not manufacture a retained file identity. Without a stability probe, positively verified busy regular files remain included as in legacy enumeration. Extension matching follows the runtime's legacy PlatformDefault behavior, independently of the directory's native case profile.
